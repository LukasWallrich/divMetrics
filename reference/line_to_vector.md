# Parse Line to Vector

Converts a comma-separated string into a numeric vector. This is a
simplified replacement for timesaveR::line_to_vector().

## Usage

``` r
line_to_vector(x, return = "vector")
```

## Source

https://lukaswallrich.github.io/timesaveR/

## Arguments

- x:

  A character string with comma-separated values.

- return:

  A character string indicating what to return. Only "vector" is
  supported.

## Value

A numeric vector of the parsed values.
