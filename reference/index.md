# Package index

## Separation Metrics

Metrics that measure differences in position along a continuum

- [`compute_cv()`](https://lukaswallrich.github.io/divMetrics/reference/compute_cv.md)
  : Compute Coefficient of Variation (CV)
- [`compute_sd()`](https://lukaswallrich.github.io/divMetrics/reference/compute_sd.md)
  : Compute Standard Deviation (SD)
- [`compute_GMD()`](https://lukaswallrich.github.io/divMetrics/reference/compute_GMD.md)
  : Compute Gini Mean Difference (GMD)

## Variety Metrics

Metrics that capture categorical variety (require binning)

- [`compute_Blau()`](https://lukaswallrich.github.io/divMetrics/reference/compute_Blau.md)
  : Compute Blau's Index

## Hybrid Metrics

Metrics that combine multiple aspects of diversity

- [`compute_Rao()`](https://lukaswallrich.github.io/divMetrics/reference/compute_Rao.md)
  : Compute Rao's Quadratic Entropy (distance-matrix form)
- [`compute_CEI()`](https://lukaswallrich.github.io/divMetrics/reference/compute_CEI.md)
  : Compute the Coverage and Evenness Index (CEI) or its Components

## Utility Functions

Helper functions for computing and visualizing diversity

- [`compute_all_metrics()`](https://lukaswallrich.github.io/divMetrics/reference/compute_all_metrics.md)
  : Compute All Diversity Metrics
- [`plot_metric_comparison()`](https://lukaswallrich.github.io/divMetrics/reference/plot_metric_comparison.md)
  : Compare Multiple Diversity Metrics
- [`report_teams()`](https://lukaswallrich.github.io/divMetrics/reference/report_teams.md)
  : Report Teams
